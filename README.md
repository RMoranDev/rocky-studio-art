
# 🎨 Rocky Studio Art

**Catálogo digital de produtos personalizados**

O Rocky Studio Art é um projeto de website desenvolvido para apresentar produtos personalizados de forma moderna, organizada e responsiva, facilitando a descoberta de produtos e o contato com clientes.

O projeto combina uma identidade visual vibrante com uma experiência de navegação simples e intuitiva.

## 🌐 Demonstração

🔗 **Acesse o site:** [Rocky Studio Art](https://rmorandev.github.io/rocky-studio-art/)

## 📌 Sobre o projeto

O objetivo do projeto é criar uma presença digital para o Rocky Studio Art, permitindo que os visitantes conheçam os produtos disponíveis e entrem em contato para solicitar informações e orçamentos.

A interface foi desenvolvida com foco em apresentação visual, usabilidade e adaptação a diferentes dispositivos.

## ✨ Funcionalidades

- Apresentação da marca e de seus produtos.
- Catálogo de produtos personalizados.
- Navegação entre as seções do website.
- Layout responsivo para diferentes tamanhos de tela.
- Acesso facilitado aos canais de contato.
- Integração com WhatsApp para atendimento e solicitações de orçamento.

## 🛍️ Produtos

O catálogo contempla diferentes categorias de produtos personalizados, como:

- Canecas
- Camisetas
- Quadros
- Lembrancinhas

## 🚀 Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/RMoranDev/rocky-studio-art.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd rocky-studio-art
   ```

3. Abra o arquivo `index.html` no navegador.

   Você também pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar o website durante o desenvolvimento.
